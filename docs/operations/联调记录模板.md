## 6. mock 回放记录

启动：

```bash
scripts/run-meeting-mock.sh
```

事件场景：

```text
happy_path      完整 snapshot → partial → confirmed → gap → speaker → resync → EOF → minutes
partial         snapshot + partial
revision_gap    snapshot + revision_gap
meeting_switch  第二个会议 snapshot
disconnect      可配合 disconnect_after 注入断线
error           degraded health + transcription gap
```

可重复故障参数：`delay_ms`、`duplicate`、`disconnect_after`。例如：

```text
ws://127.0.0.1:8200/ws/v1/meetings?scenario=happy_path&delay_ms=250
ws://127.0.0.1:8200/ws/v1/meetings?scenario=partial&duplicate=1
ws://127.0.0.1:8200/ws/v1/meetings?scenario=disconnect&disconnect_after=2
```
